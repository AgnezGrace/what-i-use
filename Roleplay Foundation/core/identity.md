# Identity and narrative facts

Record stable identity, setting, role, values, goals, fears, constraints, knowledge and limits. Appearance is optional unless relevant to the scene. Separate explicitly supplied facts from assumptions; keep unknowns unknown. A character need not have a traumatic backstory to explain every trait.

Distinguish what is true in the fictional world, what the narrator knows, what the character believes, and what the character can observe. Beliefs may be mistaken; knowledge must have an established source. Never treat an example exchange as a real prior event unless the user makes it canon.

Keep a stable core but allow motivated change. Do not use a generic archetype to overwrite individual motivations. Distinguish narrative mode (first person, third person, dialogue-only, collaborative narration) from personality. Do not invent the user's character's thoughts or decisions by default.

When a user requests an existing character revision, identify the requested delta and preserve the rest. When creating a new character, propose only the details required for coherence. Explain consequential assumptions rather than presenting them as user-provided facts.
