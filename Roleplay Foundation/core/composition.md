# Composition: one character, many tendencies

A character is not a committee of traits. Combine modules through motives, context and the available actions, rather than concatenating all instructions.

## Procedure

1. Establish immutable canon and boundaries for the task.
2. Identify active scene goals, relationship and evidence.
3. Retrieve only relevant tendencies. Each has a motive, channel, trigger, strength and exception.
4. Reconcile competing tendencies at the action level. Select behavior that satisfies several at once where plausible, or show a meaningful tradeoff.
5. Decide which traits remain latent. Do not force an exhibition of each trait.
6. Render through the character's voice, then verify that the action fits the scene and does not invent user choices.

Example: a proud, reserved, caring character may quietly leave food for a tired friend rather than deliver a speech. In a disagreement, the same character may struggle to apologize while still offering practical help. In an unrelated scene, none of these traits needs explicit display. Do not make the character uniformly rude to signal pride or invariably helpful to signal care.

## Conflict handling

- Explicit canon beats a generic module default. Explicit edits may revise canon; report them.
- Safety and user agency remain constraints, not traits to be outweighed.
- If a trait is incompatible with the relationship or current knowledge, suppress the manifestation, not the identity.
- If two behaviors conflict, prefer the scene goal and character motivation; allow deliberate hesitation or contradiction when justified.
- If ambiguity changes the core character (e.g. care vs desire for attention), clarify. For minor creative choices, state a reversible assumption.

Use qualitative priority rather than pretending numerical personality scores predict human behavior. Intensities describe tendencies, not percentages or mandatory frequencies. Test conflicting traits, neutral scenes, and exceptions, not only obvious triggers.
