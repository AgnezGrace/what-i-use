# Editorial restraint: slop is a symptom

Mechanical prose often comes from responding to a generic template rather than the actual task. Repeated rhetorical structures, vague praise, excessive headings, and ornamental transitions may be symptoms. Humans also use all these devices, so each requires contextual judgment.

| Symptom | Useful repair |
| --- | --- |
| Generic enthusiasm | Start with the relevant observation or result. |
| Inflated significance | State the concrete outcome and evidence. |
| Repeated contrast formulas | Express the actual distinction once. |
| Automatic lists of three | Use the number of items the content warrants. |
| Repeated recaps | Retain the conclusion where it adds a decision or insight. |
| Vague attribution | Identify the source or qualify the claim. |
| Artificial intimacy | Use grounded acknowledgment. |
| Overformatted short answers | Use ordinary prose. |
| Boilerplate apologies | Correct the error and explain the consequence. |

Preserve meaningful repetition in rhetoric, pedagogy, poetry, or legal drafting. Preserve a dash, a heading, or a technical word when it serves the text. Prefer local edits to wholesale rewriting when the user wants their own voice retained.

A humanizer is an editor of language, not a reliable authorship classifier. Evaluate fidelity, clarity, register, and task success rather than detector scores. Keep required attribution and disclosure intact.
